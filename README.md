# C++ 数据结构自学练习项目
本人大二自学 C++ 与数据结构的练习代码，包含线性表基础实现与 2048 小游戏Demo。

## 项目结构
```

. ├─ list/                # 线性表：顺序表 + 单向链表 │  ├─ LinkedList.h │  ├─ LinkedList.cpp │  ├─ SeqList.h │  ├─ SeqList.cpp │  └─ Test.cpp ├─ 2048/ │  └─ 2048.cpp └─ README.md

```
## 一、线性表 list（顺序表 + 单链表）
### 1. 顺序表 SeqList
基于静态数组实现，封装完整顺序表操作：
- 空表构造、数组批量初始化
- 按下标取值、按值查找位置
- 指定位置插入元素、删除元素
- 获取表长、判空、遍历打印

### 2. 单向链表 LinkedList
带头结点单链表，纯C++类封装：
- 构造空链表、数组初始化链表
- 析构函数自动释放内存，防止内存泄漏
- 节点插入、删除、查找、获取长度、遍历输出

Test.cpp 为整体功能测试代码，验证顺序表与链表所有接口。

## 二、2048 小游戏 Demo
基于 C++ + EasyX 图形库实现的图形化2048游戏，**核心逻辑全部手写**：
### 核心功能
- WASD 控制上下左右移动
- 方块压缩、合并、自动计分
- 随机生成 2 / 4 数字块
- 判断胜利（出现2048）、游戏失败（无可行移动）
- 支持 R 重新开始、Q 退出游戏

### 项目说明
- 为保证代码可直接编译运行，**背景图片加载与绘制代码已注释**
- 无图片资源依赖，安装 EasyX 即可正常游玩
- 核心算法：通过矩阵转置复用左右移动逻辑，精简代码结构

## 运行环境
- 编译工具：Visual Studio (MSVC)
- 游戏模块依赖：EasyX 图形库
- 数据结构模块：无第三方依赖，可直接编译运行

## 个人总结
本项目为课后自主练习，巩固 C++ 面向对象、指针、数组、数据结构基础与程序逻辑设计能力。
